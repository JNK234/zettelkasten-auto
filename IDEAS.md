# Future Ideas

## Content Creation Mode
- Takes a topic/question as input
- Retrieves relevant zettels via embeddings
- Suggests an outline based on connections between retrieved notes
- Exports the zettel contents as a draft skeleton
- Goal: 70% of content assembly automated, human writes the narrative

## Other Ideas
- **Query tool**: "Find notes related to X" using embeddings
- **Cluster summary**: Auto-generate MOCs (Maps of Content) for dense areas
- **Orphan finder**: List isolated notes that need connections
- **Daily prompt**: Surface a random zettel to review
